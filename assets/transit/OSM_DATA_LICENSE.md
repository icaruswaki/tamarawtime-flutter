`local_transit_graph.json` and `rail_tracks.geojson` contain data derived from
OpenStreetMap, © OpenStreetMap contributors. These derivative databases are
made available under the [Open Data Commons Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Source attribution and license information:
https://www.openstreetmap.org/copyright

The graph includes individual source URLs and relation snapshot versions.
The importer and review limitations are documented in
[`docs/local-transit-graph.md`](../../docs/local-transit-graph.md).

This notice covers the OSM-derived data, not the Flutter application code or
the separately sourced LRTA fare matrix. Map attribution remains visible in
the application.

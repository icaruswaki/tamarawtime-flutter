# Fare data — checked November 8, 2026

## Latest widely corroborated effective rates: September 28, 2026

| Mode | Minimum | Base distance | Additional per km |
|---|---:|---:|---:|
| Traditional jeepney | PHP 14.00 | First 4 km | PHP 2.00 |
| Modern jeepney | PHP 17.00 | First 4 km | PHP 2.40 |
| Ordinary city bus | PHP 15.00 | First 5 km | PHP 2.49 |
| Air-conditioned city bus | PHP 18.00 | First 5 km | PHP 2.98 |

**Caution:** The linked UNTV report appears to misstate the air-conditioned city bus minimum as PHP 15; PTV News, Philippine Star, SunStar, and other coverage agree on PHP 18. We use PHP 18. Official LTFRB PDF matrices were not directly downloadable in this environment (403), so these values should be checked against the latest posted official matrices before production.

The fare calculator is a **reference estimate**. For distance above the base band it calculates base + (distance minus base distance) * additional rate and rounds to PHP 0.25; an operator's **official fare matrix by distance band** may differ. A transit leg must have an actual verified distance and mode. Never calculate jeepney fares using straight-line distance or present this as an LTFRB-certified quote.

Student discount: 20% minimum under RA 11314; available while enrolled, including weekends and holidays. Confirm detailed eligibility and posted matrix. The sample calculator rounds the discount estimate to PHP 0.25. Do not infer other discounts or fares for unknown modes.

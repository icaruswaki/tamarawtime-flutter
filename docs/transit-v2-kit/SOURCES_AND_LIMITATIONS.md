# Verified references and data limitations (checked 2026-11-08)

- Sakay.ph historical GTFS and description: https://github.com/sakayph/gtfs
- DOTC developer license in repository, *not* a standard unrestricted open-source license: https://github.com/sakayph/gtfs/blob/master/LICENSE.md
- Official LRTA rail overview, including LRT-1 25 stations and 2024 south extension: https://www.lrta.gov.ph/railway-operations/
- DOTr MRT-3 station descriptions: https://dotrmrt3.gov.ph/about-us
- Rail station-order crosschecks: https://trains.ph/lrt-1/ , https://trains.ph/lrt-2/ , https://trains.ph/mrt-3/

The rail lists are reference names and station order; neither real-time operation nor schedule status has been checked. Station coordinates remain null pending reviewed and licensed geographic source. Some named stations are interchange points, but transfer walking conditions vary and were not measured. Historical GTFS should not be used as live operating information. The Sakay feed is not enclosed in the package.
